# Требования к ВКР МФТИ (ВШПИ)
> Источник: `diploma/Требования_к_бакалаврской_работе_МФТИ.docx`  
> ГОСТ Р 7.0.110-2025 + ГОСТ Р 7.0.100-2018

---

## 1. Объём и структура

**Объём основного текста: 40–60 страниц** (без приложений).

**Порядок структурных элементов** (строго соблюдать):
1. Титульный лист (Приложение А)
2. Аннотация (Приложение Б)
3. Содержание (Приложение В)
4. Обозначения и сокращения (при необходимости, Приложение Г)
5. Основной текст: Введение → Разделы с подразделами → Заключение
6. Список использованных источников (ГОСТ Р 7.0.100-2018, Приложение Д)
7. Приложения (при необходимости)

**Содержание ВКР должно включать:**
- Обоснование актуальности и анализ состояния проблемы
- Постановку задачи и цели работы; список задач для достижения цели
- Обоснование выбора методов и средств
- Описание реализации
- Анализ и интерпретацию результатов; оценку достоверности
- Рекомендации по использованию (практическая значимость)
- Обобщение результатов и план дальнейших действий

## 2. Страница

| Параметр | Значение |
|---|---|
| Формат | A4, книжная ориентация |
| Поле левое | 30 мм |
| Поле правое | 15 мм |
| Поля верхнее и нижнее | по 20 мм |
| Нумерация страниц | нижний колонтитул, правая сторона, ≥ 1 см от края |
| Титульный лист | входит в нумерацию, номер **не ставится** |

---

## 3. Шрифт и цвет

- **Один шрифт** на весь документ — Times New Roman
- **Основной текст и заголовки** — 14 пт
- **Заголовки разделов (первый уровень)** — **16 пт, полужирный**
- **Код** — Courier New (единственное исключение)
- **Таблицы и иллюстрации** — тот же шрифт, но допускается уменьшение до минимум **10 пт**
- **Цвет текста** — только **чёрный** (в основном тексте и таблицах другие цвета запрещены)
- В схемах и иллюстрациях — допускаются градации серого; заливка — белая

---

## 4. Абзац основного текста

- Межстрочный интервал: **1,5 строки**
- Абзацный отступ: **1,25 см**
- Отступы **до и после абзаца = 0**
- При центрировании (заголовки, подписи) — абзацный отступ **не применяется**

---

## 5. Заголовки разделов (первый уровень)

- Кегль **16 пт**, полужирный
- По центру, без абзацного отступа
- **Начинается с новой страницы** (как и Аннотация, Содержание, Введение, Заключение, Список источников)
- Точка в конце **не ставится**
- Отделяется от следующего абзаца **двумя пустыми строками**
- Формат нумерации: `Раздел 1. Название раздела` (не «ГЛАВА 1»)

**Пример:**
```
Раздел 1. Постановка задачи проектирования
информационной системы
```

---

## 6. Заголовки подразделов (второй уровень)

- Кегль 14 пт, **полужирный**
- По левому краю (как основной текст), без абзацного отступа
- Точка в конце **не ставится**
- **До подраздела** — две пустые строки от предшествующего текста/заголовка
- **После заголовка** — одна пустая строка до текста
- Подраздел **продолжает страницу** (не начинается с новой, кроме случаев «висячих строк»)

**Пример нумерации:** `1.1 Современное состояние проблемы`

---

## 7. Выводы по разделу — ОБЯЗАТЕЛЬНЫ

- Обязательный подраздел в конце каждого раздела
- Оформляется как подраздел (те же правила форматирования)
- Абзацы **нумеруются**, начиная с 1
- Название: `Выводы по разделу N`

**Пример:**
```
Выводы по разделу 1

1. В ходе анализа литературных источников выявлены особенности...
2. Установлено, что...
```

---

## 8. Иллюстрации (рисунки)

- Размещаются **после абзаца с первой ссылкой** (или на следующей странице)
- Выравнивание по центру, пустая строка **до и после** изображения
- Ссылка в тексте **обязательна** и **предшествует** иллюстрации:
  - Описательная: «на рис. 1.1 представлены параметры...»
  - Отсылочная: «используется единый стиль (рис. 1.1)»
- **Подпись** — ниже изображения, пустая строка между изображением и подписью, по центру, без абзацного отступа
- Формат подписи: `Рисунок N.M. Название с заглавной буквы` (точка в конце **не ставится**)
- Нумерация **двухуровневая**: первый уровень = номер раздела, второй = порядковый номер в разделе

**Пример:** `Рисунок 2.3. Схема алгоритма повышения точности`

⚠️ **Нельзя заканчивать подраздел или раздел иллюстрацией** — после должен идти текст.

---

## 9. Таблицы

- Размещаются **после абзаца с первой ссылкой** (или на следующей странице)
- Ссылка в тексте обязательна и предшествует таблице
- **Заголовок над таблицей**, пустая строка между заголовком и предшествующим текстом
- Заголовок — по центру, без абзацного отступа; допускается полужирный
- Формат заголовка: `Таблица N.M. Название с заглавной буквы` (точка в конце **не ставится**)
- Нумерация **двухуровневая**: раздел.порядковый номер в разделе
- Стиль таблицы: **простая сетка**, линии 0,25 мм, чёрный цвет, одинаковый во всём документе
- После таблицы — **пустая строка** перед следующим текстом

**Пример:** `Таблица 2.3. Основные метрики модели`

⚠️ **Нельзя заканчивать подраздел или раздел таблицей** — после должен идти текст.

---

## 10. Списки

- **Нумерованные**: арабская нумерация, `1. Текст с заглавной буквы.` (номер отделяется точкой + пробел; каждая позиция заканчивается точкой)
- **Ненумерованные**: длинное тире `—` или буллет `•` (дефис `-` **не допускается**)
- Абзацный отступ списков = абзацному отступу основного текста (1,25 см)

---

## 11. Формулы

- Представляются в **редактируемом виде** (не картинки), кегль 14 пт
- Короткие (один символ высотой) — допускается в строке текста
- Длинные (дроби, суммы, интегралы) и те, на которые есть ссылки — **отдельная строка**, пустые строки сверху и снизу
- Выравнивание: **по левому краю** по единой линии для всех формул
- Номер формулы: **у правого поля в круглых скобках**, двухуровневая нумерация `(N.M)`
- Нумеруются только те формулы, на которые есть ссылки
- Обозначения — **до или сразу после** формулы; без абзацного отступа перед «где»

---

## 12. Ссылки на источники

- **Квадратные скобки**: `[N]` или `[N, стр. X]` для прямых цитат
- Нумерация **сквозная** для всей работы
- Порядок: **по упоминанию в тексте** (рекомендуется) или по алфавиту
- ⚠️ **Источники без ссылки в тексте — запрещены**
- Несколько источников: `[1, 2]`
- Прямая цитата: `«текст цитаты» [N, стр. X]`

---

## 13. Аннотация — формат

Строгий формат первой строки:
```
Выпускная квалификационная работа, N с., M рис., K табл., P источн., Q прил.
```
Затем — ключевые слова заглавными буквами, далее блоки:
- Объект исследования
- Предмет исследования
- Цель работы
- Методы исследования
- Результаты

---

## 14. Список использованных источников — формат (ГОСТ Р 7.0.100-2018)

**Книга одного автора:**
```
Фамилия, И. О. Название : подзаголовок / И. О. Фамилия. – Город : Издательство, год. – N с. – ISBN. – Текст : непосредственный.
```

**Статья из журнала:**
```
Фамилия, И. О. Название статьи / И. О. Фамилия // Журнал. – год. – № N. – С. X–Y. – Текст : непосредственный.
```

**Материал из интернета:**
```
Фамилия, И. О. Название / И. О. Фамилия // Сайт : [сайт]. – URL: https://... (дата обращения: ДД.ММ.ГГГГ).
```

## 15. Критические несоответствия текущего build_vkr.py

| # | Проблема | Требование |
|---|---|---|
| 1 | Заголовки разделов 14 пт | Должны быть **16 пт** |
| 2 | `add_heading1` → "ГЛАВА N. НАЗВАНИЕ" заглавными | Должно быть `Раздел N. Название` (с заглавной) |
| 3 | Нумерация таблиц сквозная: "Таблица 5" | Должна быть двухуровневая: "Таблица 2.3" |
| 4 | Нумерация рисунков сквозная: "Рисунок 1" | Должна быть двухуровневая: "Рисунок 2.1" |
| 5 | Выводы по разделу — текстом без нумерации | Абзацы должны быть **пронумерованы** начиная с 1 |
| 6 | Нет раздела «Содержание» в документе | Содержание **обязательно** |
| 7 | Нет страничной нумерации | Нижний колонтитул, правая сторона |
| 8 | Возможно space_before/space_after ≠ 0 | Отступы до/после абзаца = 0 |
| 9 | Некоторые разделы заканчиваются таблицами | Запрещено — нужен текст после |
| 10 | `add_heading2` не делает отступ в 2 строки до | Два пустых абзаца перед подразделом |
| 11 | Межстрочный интервал 1.5? (line=360 = 1.5×240) | Проверить: 360/240 = 1.5 ✓ |
